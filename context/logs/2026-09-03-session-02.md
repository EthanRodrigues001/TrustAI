## Design notes worth keeping

**Perplexity is display-only.** The brief mandates it, so it is shown
prominently — but it carries weight 0 in the score. Whole-answer perplexity is
diluted by function words; **entity perplexity (A3)** is what actually detects
fabrication, and that carries the weight. Both are shown.

**Heaviest parameter is C2 (0.35)** — verbatim quote verification. Everything
else is supporting evidence around that one check.

**The wire-story trap (D3)** is the most under-appreciated parameter. Three sites
carrying the same news-agency copy looks like three-way corroboration and is
actually one source. Detected by pairwise text similarity.

**`quoteVerified: false` with a non-null quote** = the model fabricated a quote
that isn't on the page it cited. Loudest possible catch; build the demo around it.
