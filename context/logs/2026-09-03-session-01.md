## Key exchanges

**Q: Is there a database of trusted websites?**
No single authoritative one. Wikipedia's WP:RSP list is the best free option
(~600 media sources, labeled). NewsGuard is the proper commercial answer but
enterprise-priced — we name it as the upgrade path. Everything else (Tranco,
Open PageRank) measures popularity, not trust. So: composite scoring.
-> D-03

**Q: What if a domain isn't in the list?**
Escalation chain: corroboration with trusted sources, independence check, page
structural heuristics, RDAP domain age, Wikidata org existence, LLM classifier
as last resort. If still unknown, it counts for zero.
-> D-04

**Central insight established:** don't validate the answer, validate the answer
*against re-fetched evidence*. Gemini's grounding metadata is a claim, not proof.
The signature failure is a real, reputable URL cited for a claim that page never
made.
-> D-01, D-02
